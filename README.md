# Dr. Derick Jose — Professional Website

A responsive, single-page professional profile website inspired by the clean editorial layout of the reference website.

## Preview locally
Open `index.html` in a modern browser. Keep `dr-derick-jose.png` in the same folder.

## Before publishing
- Confirm current professional registration status and approved title/credentials.
- Confirm the preferred practice location, clinic name, appointment process, and any social/profile links.
- Replace the generated portrait with an approved real headshot if preferred.
- Have all medical claims, services, and compliance requirements reviewed before going live.
- Deploy the folder to a hosting provider (for example, Netlify, GitHub Pages, or your own domain hosting).

This is a static website; the contact buttons open the visitor's email app or phone dialler. It does not include online booking or a backend form.
